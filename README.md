# Demo · Restaurante El Playón

Vista previa sencilla para presentar una dirección visual inicial al Restaurante El Playón.

## Alcance

- Portada y propuesta visual
- Breve presentación del restaurante
- Muestra de tres platillos
- Horario, ubicación y contacto por WhatsApp
- Diseño adaptable a teléfonos y computadoras

La demo no incluye el menú completo, reservas, galería ampliada ni las funciones de la versión final.
